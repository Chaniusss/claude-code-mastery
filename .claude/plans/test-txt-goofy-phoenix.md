# /doctor 점검 결과와 적용 계획

## 요약

설치 상태는 건강하고 버전도 최신(2.1.304)입니다. 정리할 만큼 안 쓰는 확장(스킬, 플러그인, MCP 서버)은 없습니다. 실제로 손볼 항목은 두 가지입니다. 프로젝트 `CLAUDE.md`의 낡은 문장 1줄 삭제와, 자동 모드(auto)를 기본 권한 모드로 설정하는 것입니다. 모두 되돌릴 수 있습니다.

점검 범위: 최근 세션 기록 11개, 약 2일치. 표본이 작아서 "안 쓰는 확장" 판단은 보수적으로 했습니다.

## 경고 (조치 없음)

- `.claude/settings.local.json`에 `permissions.allow: ["Bash"]`가 있습니다. 모든 Bash 명령을 묻지 않고 허용하는 규칙이라 자동 모드의 분류기 검사도 Bash에는 사실상 적용되지 않습니다. 의도한 설정인지 확인해 보세요. 좁히고 싶으면 말씀해 주세요.

## 제안 (확인 후 적용)

### A. 프로젝트 `CLAUDE.md` 낡은 줄 삭제 (점검 3, 체크인 파일 수정)

`C:\my-workspace\claude-code-mastery\CLAUDE.md`의 "프로젝트 개요"에서 아래 줄을 삭제합니다. 이미 `index.html`, `css/`, `js/`가 있어 사실과 다르고, 세션마다 잘못된 전제를 줍니다.

```
- 현재 소스 파일은 아직 없습니다. 로드맵에 따라 추가됩니다.
```

되돌리기: 위 줄을 다시 추가하면 됩니다. 커밋은 하지 않습니다.

### B. 자동 모드를 기본 권한 모드로 (점검 8, 사용자 설정)

`~/.claude/settings.json`에 `"permissions": {"defaultMode": "auto"}`를 추가합니다. 기존 키(`env`, `model`, `autoUpdatesChannel`, `tui`)는 그대로 둡니다.

- 모든 프로젝트에 적용됩니다. 프로젝트 설정이 `defaultMode`를 따로 지정하면 그쪽이 우선합니다.
- 자동 모드를 쓸 수 없는 환경이면 CLI가 알림과 함께 기본 모드로 되돌아가므로 잠길 일은 없습니다.
- 되돌리기: 해당 키를 지우면 됩니다.

## 적용 후 검증

- `~/.claude/settings.json`을 `node`로 파싱해 JSON이 깨지지 않았는지, 기존 키가 유지됐는지 확인
- `CLAUDE.md`에서 삭제한 줄만 사라졌는지 확인
